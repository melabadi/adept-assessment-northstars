# Approved architecture standards (synthetic)

Each `STD-*.md` file is one approved standard. Its front matter gives a stable `id`, a `version`, and a `scope`:

- `all` applies to every team.
- `small-team` applies only to the small-team operating profile (one squad, minimal operations).
- `enterprise` applies only to the enterprise profile (several departments, a central platform team).

Cite a standard by id and version, for example `STD-OBS-001 v1.2`. The ADR checker rejects ids that do not exist and versions that are not current.
