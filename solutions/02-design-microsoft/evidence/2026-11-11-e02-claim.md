## The change

STD-OPS-002 says: *Enterprise workloads call model and agent endpoints through the central AI gateway (Azure API Management) to enforce per-department quotas, rate limits, and usage reporting.* E02 asks *How should RequestHub call the model endpoint for live triage in production?* Its label lists the claims a right answer may state, and one of them is enough. One claim was added, in [`eval_cases.jsonl`](../eval_cases.jsonl):

| E02's `states` | Claims |
| --- | --- |
| Before | `through* gateway`, `via* gateway`, `gateway path`, `use* gateway`, `behind* gateway` |
| After | the same five, and `through* api management` |

A claim's words must come in order, in one clause, with at most three other words between one and the next (`CLAIM_GAP` in [`checks.py`](../function/advisor_core/checks.py)). *through the central Azure API Management AI gateway* puts six words between *through* and *gateway*, and *through Azure API Management, the central AI gateway* ends the clause at the comma. The new claim works like `through* gateway`, with the same window and the same negation handling, so *Do not route calls through Azure API Management* states nothing. E02's `rejects` (`call* direct*`, `direct* call*`) and `evidence`, the other cases, the held-out cases, and `checks.py` are unchanged.

Going back to `gpt-6-luna` published version 6, whose definition equals version 3's, and going back to `gpt-6.1-sol` published version 7, whose definition equals version 5's. `azd deploy`, started at 16:20:16, put this code in the Function in 35 seconds; the deployment finished at 16:21:02.

```python
import json, sys
sys.path.insert(0, "function")
from advisor_core import checks

def grades(item: dict, output_text: str, output_items: list, label: dict) -> dict:
    """item: an output item's datasource_item; output_text: the agent's final message; output_items: its sample.output."""
    scored = checks.evaluate_item({**item, "expectConclusion": json.dumps(label),
                                   "sample": {"output_text": output_text, "output_items": output_items}})
    return {kind: checks.verdict(scored, kind) for kind in ("citations", "access", "grounding", "abstention", "conflicts")}
```
