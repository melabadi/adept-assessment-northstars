# STD-AI-001 · AI output is advisory (v1.0)

AI output is advisory unless a documented exception is approved by the architecture board. Approvals, rejections, payments, and access grants always require a human decision. Tools exposed to an agent are read-only or narrowly scoped to the record being processed, and every tool call is audited.
